## 题目描述

训练队中有 $n$ 名同学。每名同学有姓名和三项训练成绩。

请找出三项成绩总和最高的同学，输出其姓名和总分。如果多人总分相同，输出输入顺序最靠前的同学。

## 输入格式

第一行输入一个整数 $n$。

接下来 $n$ 行，每行包含一个不含空格的姓名，以及三个整数成绩。

## 输出格式

输出最佳队员的姓名和总分，中间用一个空格分隔。

## 数据范围

$1 \le n \le 10^4$，每项成绩均为 $0$ 到 $100$ 的整数，姓名长度不超过 30。

## 输入样例 1

```
3
Alice 90 80 70
Bob 88 92 85
Carol 100 70 60
```

## 输出样例 1

```
Bob 265
```

## 输入样例 2

```
1
Solo 0 0 0
```

## 输出样例 2

```
Solo 0
```
