## 题目描述

一份训练记录由 $n$ 行 $m$ 列整数构成。请分别计算每一行所有数字的和。

## 输入格式

第一行输入两个整数 $n,m$。

接下来 $n$ 行，每行输入 $m$ 个整数。

## 输出格式

输出一行 $n$ 个整数，第 $i$ 个整数表示第 $i$ 行的元素之和。相邻整数之间用一个空格分隔。

## 数据范围

$1 \le n,m \le 100$，$-10^6 \le a_{i,j} \le 10^6$。

## 输入样例 1

```
2 3
1 2 3
4 5 6
```

## 输出样例 1

```
6 15
```

## 输入样例 2

```
1 4
5 -2 7 0
```

## 输出样例 2

```
10
```
