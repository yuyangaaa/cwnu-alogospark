## 题目描述

共有 $n$ 组整数，每组包含两个整数 $a_i,b_i$。对每一组取较大的数，再计算这些较大值的总和。

建议编写一个返回两个整数中较大值的函数，并在循环中重复调用。

## 输入格式

第一行输入一个整数 $n$。

接下来 $n$ 行，每行输入两个整数 $a_i,b_i$。

## 输出格式

输出所有较大值的总和。

## 数据范围

$1 \le n \le 10^5$，$-10^9 \le a_i,b_i \le 10^9$。

## 输入样例 1

```
3
1 5
8 2
4 4
```

## 输出样例 1

```
17
```

## 输入样例 2

```
1
-3 -7
```

## 输出样例 2

```
-3
```
