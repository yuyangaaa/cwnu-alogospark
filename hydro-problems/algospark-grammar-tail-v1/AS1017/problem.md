## 题目描述

读取 $n$ 名同学的训练分数，请输出最高分、最低分，以及获得最高分的人数。

## 输入格式

第一行输入一个整数 $n$。

第二行输入 $n$ 个整数，表示每名同学的分数。

## 输出格式

在一行中依次输出最高分、最低分和最高分人数，三个整数之间用一个空格分隔。

## 数据范围

$1 \le n \le 10^5$，$0 \le a_i \le 100$。

## 输入样例 1

```
5
80 95 72 95 88
```

## 输出样例 1

```
95 72 2
```

## 输入样例 2

```
1
60
```

## 输出样例 2

```
60 60 1
```
