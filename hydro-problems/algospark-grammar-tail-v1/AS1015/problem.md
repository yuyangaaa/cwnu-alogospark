## 题目描述

一场训练中共有 $n$ 道小题，第 $i$ 道小题带来的积分变化为 $a_i$。积分变化可能为正数，也可能为负数。

请计算完成全部小题后的积分变化总和。

## 输入格式

第一行输入一个整数 $n$。

第二行输入 $n$ 个整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

输出一个整数，表示积分变化总和。

## 数据范围

$1 \le n \le 10^5$，$-10^9 \le a_i \le 10^9$。

## 输入样例 1

```
5
3 4 -2 8 1
```

## 输出样例 1

```
14
```

## 输入样例 2

```
1
-7
```

## 输出样例 2

```
-7
```
